# Alarm Sound Files

This directory contains the default alarm sound files for the app.

## Required Sound Files

Add the following MP3 files to this directory:

1. **alarm_sound.mp3** - Classic alarm sound
2. **gentle_wake.mp3** - Gentle wake-up sound
3. **morning_birds.mp3** - Morning birds chirping
4. **ocean_waves.mp3** - Ocean waves sound
5. **soft_chime.mp3** - Soft chime sound
6. **energetic.mp3** - Energetic alarm sound
7. **peaceful.mp3** - Peaceful wake-up sound
8. **upbeat.mp3** - Upbeat alarm sound

## File Format

- Format: MP3
- Recommended: 16-bit, 44.1kHz or 48kHz
- Duration: 10-30 seconds (will loop during alarm)
- File size: Keep under 1MB per file for optimal performance

## Adding Sounds

1. Place your MP3 files in this directory
2. Ensure filenames match exactly (case-sensitive)
3. Run `flutter pub get` after adding files
4. Rebuild the app

## Free Sound Resources

You can find free alarm sounds at:
- Freesound.org
- Zapsplat.com
- Pixabay.com (audio section)

Make sure to check licensing requirements for any sounds you use.
